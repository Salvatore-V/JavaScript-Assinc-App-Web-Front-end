# JavaScript Assíncrono - Aplicação Web Front-end

Este projeto consiste numa aplicação web desenvolvida no âmbito do estudo de **JavaScript Assíncrono**, focada na gestão de tags, manipuladores de eventos assíncronos e simulação/integração de operações no front-end.

---

## Tecnologias e Ferramentas Utilizadas

* **Linguagem / Scripting:** JavaScript (ES6+, Promises, Async/Await)
* **Estruturação & Estilização:** HTML5, CSS3
* **Recursos Visuais:** SVG, PNG (Ativos de Interface)
* **Controle de Versão:** Git, GitHub

---

Principais Casos Implementados e Funcionalidades
A aplicação contempla fluxos interativos no front-end focados em requisições e assincronismo:

Manipulação de Eventos Assíncronos: Tratamento de requisições e ações do usuário sem bloquear a interface.

Interface Dinâmica: Renderização e modificação de elementos do DOM em resposta a fluxos de dados assíncronos.

Componentes de Interface: Gestão de formulários, ícones interativos e feedbacks visuais para o usuário.

Como Executar o Projeto Localmente
Pré-requisitos: Certifique-se de ter um navegador web moderno instalado (Google Chrome, Firefox, Edge, etc.).

Navegar até a pasta do projeto:

Bash
cd 3802-javascript-assincrono-aula-05
Executar a Aplicação:

Abra o arquivo index.html diretamente no seu navegador, ou

Utilize a extensão Live Server no VS Code para rodar a aplicação localmente.
